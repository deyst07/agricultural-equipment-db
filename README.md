
# Учет сельскохозяйственной техники

**Индивидуальный проект по дисциплине «Базы данных»**

---

## О проекте

Разработка реляционной базы данных для автоматизации учета сельскохозяйственной техники одного сельскохозяйственного предприятия.

Система предназначена для централизованного хранения и обработки информации о:

- Сельскохозяйственной технике и ее производителях;
- Сотрудниках предприятия;
- Земельных участках и сельскохозяйственных работах;
- Техническом обслуживании и ремонте;
- Заправках и расходе топлива.

## 🛠 Технологии

- **Язык запросов:** SQL
